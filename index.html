01 / INSTALL THE SKILL

先安装 Skill，
再选你的视觉方向。

把 FrontArt 装进 Codex。之后只需说出想要的风格和产品任务，就能调用配方生成可交互的页面。

在 Codex 新对话中发送 用 $skill-installer 从 GitHub 仓库 fendouweiqian/frontart-design 的 skill/ 目录安装 frontart-design。 安装完成后新开对话，输入“用 $frontart-design，按「社区论坛目录」风格，做一个摄影社区网站”。 查看 GitHub 仓库 ↗

02 / THE IDEA

不是再写一句“做得更好看”。
是先找到属于这个产品的视觉逻辑。

优秀界面背后有清晰的取舍：信息如何排列，图像怎样成为主角，交互如何反馈。FrontArt 把这些决定整理成一张张配方，让 AI 有具体的设计依据。
