# 拾野博客原型

面向手机阅读的原创演示博客。直接打开 `index.html` 即可使用，也可在项目根目录运行 `python -m http.server 4173`，访问 `/test/shiye/`。

主要路径：发现列表 → 文章详情 → 收藏 → 返回发现 → 收藏页再次阅读。分类、搜索、浏览器后退和取消收藏均可使用；收藏保存在当前浏览器的 `localStorage` 中。文章、作者、日期均为演示内容，不对应真实博客或发布记录。
