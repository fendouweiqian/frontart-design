# 一句话调用生成的摄影社区

这是按已安装的 `$frontart-design` Skill 和 `forum-lounge / 社区论坛目录` 配方生成的独立静态原型。页面内容、账号、主题和统计数据均为原创虚构示例，没有复用 `test/one-sentence-forum/` 的代码。

## 交互验收

- 访问 `index.html` 或在项目根目录启动 `python -m http.server 4173` 后打开 `/test/generated-by-one-sentence/`。
- 首页支持按类别筛选和搜索主题；点击主题行进入二级详情。
- 详情页显示连续回复、面包屑和“返回主题目录”路径。
- 在回复框输入内容并发布，会将新回复插入当前讨论串并显示“回复已发布，讨论继续。”反馈；空提交会显示校验提示。
- 顶部“关于社区”打开说明对话框，可回到主题目录。

## 配方依据

采用 `forum-lounge`：浅色全页、居中搜索、公告与类别入口、密集主题目录和进入主题后的连续回复。来源记录见安装后的 `skill/references/recipes/index.md` 与 `skill/references/recipes/catalog.json`，公开证据范围为 Linux.do 公开论坛首页于 2026-11-04 的可观察布局规律。本页面只抽象信息层级与交互方式，不复制品牌、帖子、用户或源代码。

主题行使用 Unsplash 公开图片链接作为摄影内容缩略图，仅用于原型展示；正式发布前应根据部署策略固化图片并核对具体图片许可。
