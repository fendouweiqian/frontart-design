# 拾野博客使用说明

拾野是一个原创博客 H5 原型，供手机读者浏览行走、空间和阅读主题的文章，并保存想再次阅读的内容。文章、日期和署名均为演示信息，尚未接入发布后台。

## 入口与使用

在浏览器打开项目的 `test/shiye/index.html`。手机端底部有“发现”“收藏”“关于”三个入口；桌面端入口位于顶部。

1. 在“发现”浏览最近更新，或使用搜索框和分类切换找文章。
2. 点文章图片或标题进入详情，阅读后点“收藏文章”。页面会提示已收藏，底部收藏入口显示数量。
3. 点“返回发现”回到列表；进入“收藏”可再次打开文章，也可取消收藏。

收藏保存在当前浏览器本地。清除该站点的本地存储后，收藏记录会消失；不同设备间不会同步。图片依赖 Unsplash 网络服务，来源和许可说明见 `test/shiye/README.md`。本功能仅为本地可运行原型，未声明已部署上线。
