# 设计配方库与来源规范

FrontArt 面向设计网站和平台中立的通用手机原型。配方将优秀界面里可复用的布局、信息层级、影像、字体和交互规律整理成 Skill 可搜索的数据与可复制提示词。

## 收录标准

每条配方须有清楚来源、适用场景、可复用规律、限制和对应演示。演示至少提供首页或列表、一个可进入的二级内容或操作页、返回路径和一项可见的操作反馈；可复制提示词必须说明同一浏览路径。先检查与已有条目是否重复；无法说明差异时不新增。

来源网站的 Demo 应依据可观察页面还原其主要布局、模块顺序、信息密度、配色关系、字体气质和组件位置。次要业务能力可以精简或做本地模拟，但要标明示例内容和功能边界。复用视觉规律不等于复用品牌标识、原文、用户内容、源代码或无许可素材；公开页面不可访问时，记录限制并暂停该来源的视觉复刻。

WordPress 免费主题可查看 WordPress.org 目录和官方演示。付费主题只使用无需绕过权限即可公开获取的演示、文档、截图或主题包；无法公开获取的部分不分析。活跃安装量、下载量、销量或排名需以当前官方页面或可信数据源核验，不能从评价数或常见程度推算。

## 来源边界

参考来源只用于理解界面规律。不得复制其他项目的商标、原文、代码、用户内容或没有许可的图片。展示照片需有明确可核验来源，正式部署前检查素材许可并决定是否固化到本地。

内容区分可观察事实、设计判断和待核验信息。保留来源 URL、访问日期、证据范围和许可；主题版本与评分等易变化数据应在重新核对后更新。

## 修改位置

- `skill/references/recipes/catalog.json`：Skill 查询使用的结构化目录。
- `skill/references/recipes/index.md`：面向维护者的可读目录。
- `skill/references/recipe-template.md`：新增条目模板与门槛。
- `demos/`：有独立展示的可运行案例。目录标识应与配方 ID 一致。
