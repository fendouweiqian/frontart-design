## 操作入口与后续使用

1. 登录 [Google Search Console](https://search.google.com/search-console/)，选择资源 `https://frontart.fendouweiqian.top/`。从“编制索引 → 站点地图”查看 sitemap 状态、发现页数和上次读取时间；从顶部“网址检查”输入完整 URL，查看具体收录情况。页面有实际更新且需要主动通知时，可请求编入索引，无须重复提交同一未变更页面。
2. 登录 [Bing Webmaster Tools](https://www.bing.com/webmasters/)，选择 `frontart.fendouweiqian.top/`，进入“Sitemaps”查看处理结果；进入“URL Inspection”检查具体页面。新提交时的 Processing 应与最终抓取结果分开记录。
3. 首页验证标记位于 `index.html`。IndexNow 文件为根目录 `e443fa1683b91bade13543d59f4e9983.txt`，正文须保持与文件名中的 key 一致。`scripts/build-site.mjs` 会将它复制到 `dist/`；后续全量发布时须保留这些验证内容。
4. 新增或修改可索引页面后，更新 `sitemap.xml`，构建并上传；确认公网 sitemap、对应页面及 key 文件可用，再通知搜索引擎。IndexNow 使用 `POST https://api.indexnow.org/indexnow`，JSON 包含 `host`、`key`、`urlList`，仅提交本域名的 HTTPS URL。无需在网页或仓库保存站长平台登录凭证。
5. 百度入口为 [普通收录](https://ziyuan.baidu.com/linksubmit/index?site=https://frontart.fendouweiqian.top/)；搜狗入口为 [链接提交](https://zhanzhang.sogou.com/index.php/sitelink/index)。百度当前配额显示为 0，先查看配额或数据反馈是否更新，再决定是否提交；搜狗避免重复提交相同链接。两家均应以明确回执或后续收录数据为准。
