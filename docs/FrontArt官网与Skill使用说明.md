# FrontArt 官网与 Skill 使用说明

当前交付为本地可预览的 MVP，未创建 GitHub 仓库，未绑定域名，也未部署线上。官网地址 `frontart.fendouweiqian.top` 仍是计划中的 MVP 地址，不代表已上线。

## 浏览风格配方

官网有三层页面：首页介绍 FrontArt 并展示少量精选；从“浏览全部配方”进入二级配方库页；点配方卡进入三级单条详情页。

在二级配方库页按分类或关键词搜索配方，搜索覆盖名称、类型、参考来源、用途和视觉标签。键盘按 `/` 可聚焦搜索框。

配方库卡片提供两个入口：“体验 Demo”直接打开完整页面，适合先验证网站或 H5 的浏览感受；“查看配方”进入三级详情页，查看来源和布局、配色、字体、内容层级等规律。详情页首屏可以立即进入 Demo，也可以复制一句话调用示例。安装 Skill 后，用户只需要把产品名称、目标用户和核心任务填入这句话，例如“用 `$frontart-design`，按「社区论坛目录」风格，为摄影爱好者设计并实现一个可交互的社区网站，核心任务是浏览主题并回复。” Demo 以完整页面打开，直接操作首页/列表和二级内容页；不把原型缩进详情页的小框中。进入 Demo 后，桌面端可从右下角、手机端可从顶栏打开可收起的调用示例面板，手机入口不会遮住帖子与回复。

12 条配方均有可点击的双层原型：信息流进入动态详情，论坛目录进入主题，兴趣广场进入帖子，手机发现页进入内容；其余配方分别进入故事、长文、资料项、案例、商品、文章、产品或工具操作页。X 参考 Demo 使用公开首页观察到的白底左侧主导航、中间推荐/关注切换和连续时间线、右侧搜索/趋势/关注建议结构；Linux.do 参考 Demo 使用公开论坛首页观察到的紧凑顶栏、居中标题与搜索、公告、类别筛选、横向视图切换，以及主题/参与者/回复/浏览/活动目录结构。帖子内容、账号信息均使用虚构数据。账号、服务端数据、支付和管理能力会按展示目的简化，并在页面注明。

## 使用 Skill

Skill 源文件位于 `skill/SKILL.md`，公开仓库为 [fendouweiqian/frontart-design](https://github.com/fendouweiqian/frontart-design)。Codex 用户在新对话中输入 `$skill-installer`，说明“从 GitHub 仓库 `fendouweiqian/frontart-design` 安装 `skill/`”；安装完成后新开对话或重启 Agent，再执行一句话调用。也可以手动把 `skill/` 复制到 Agent 的 Skills 目录。

Skill 会先读项目和真实任务，再搜索 `skill/references/recipes/catalog.json`，选取一至三个互补配方并说明如何适配。它覆盖 Web UI 与平台中立手机原型，不要求每次机械产出三套方案；只有用户要求探索或方向确有不确定性时才比较多个选项。

## 本地运行

可直接打开 `index.html`，也可在 PowerShell 项目目录启动 `python -m http.server 4173` 后访问 `http://localhost:4173/`。本地静态预览无需构建和安装依赖。
